# V1.3.3 – Tail Continuity QA Report

Stand: 04.10.2026

## Scope

V1.3.3 addresses visible shaft/tail discontinuities by moving the fix into the shared authoring, geometry and QA pipeline rather than hiding individual presets with local trims.

The implementation keeps the legacy catalog contract backward-compatible while adding:

- global dart-axis analysis before tail authoring,
- width/centerline profiling,
- canonical shaft-core extraction,
- optional source-derived rear-root extraction,
- one-sided flight-leak classification at integrated roots,
- generic visible-join geometry,
- a smooth shaft-core -> rear-root bridge,
- hard Tail-QA metrics,
- source/shaft/root/flight/assembly comparison panels,
- browser/WebGL continuity checks.

No changes are made to `autodarts-xconfig`.

## Source-grounded vs. approximated

The shaft-core and any emitted rear-root reuse source pixels. RGB artwork is not redrawn or locally warped. The authoring pipeline may globally rotate a source to normalise the dart axis and may remove pixels classified as non-axial flight leakage from the root crop.

Flight Plane A keeps the existing provenance rules. Plane B remains approximated where no independent source exists. V1.3.3 does not claim that unknown rear flight faces are reconstructed from source.

## Automated QA

The final V1.3.3 validation runs:

- deterministic tail-authoring tests,
- catalog and provenance validation,
- geometry continuity tests,
- deterministic static visual QA,
- source-vs-render panels,
- browser/WebGL QA,
- all-preset pose galleries,
- WebGL context-loss recovery.

Hard runtime invariants in the accepted run:

- presets: 16,
- maximum tip drift: 0 px,
- maximum Barrel -> Rear visible join delta: approximately machine epsilon,
- maximum Shaft -> Root visible join delta: 0 mm,
- maximum join slope delta: 0,
- WebGL context-loss restore: PASS,
- post-restore renderer self-test: PASS.

The Tail-QA catalog gate uses the planned 8% median-shaft-width limit for shaft-axis residual and separately gates width variation, local center jump, alpha haze and root alignment.

## Visual comparison / iterative corrections

The QA images were manually compared with their source images, with particular focus on:

- AT-AT,
- Mandalorian,
- Prodigy,
- Shift,
- World Champion,
- Clemens 95K,
- the all-presets pose contact sheet.

Corrections made during that review include:

1. The first tail confidence mapping incorrectly rejected visually stable shafts. Confidence was recalibrated to the actual acceptance envelope instead of linearly penalising already-valid cores.
2. Mandalorian and Vader initially showed a large measured root-axis offset because the photographed rear crop already contained one-sided flight-base pixels. Those pixels are now classified out of the axial root instead of relaxing the alignment gate.
3. Prodigy, Shift and Clemens 95K initially generated clean shaft-core assets but the catalog still selected the legacy rear crop when no explicit root was detected. The catalog now uses the canonical shaft-core independently of whether a root is emitted.
4. A software-QA pose for Clemens 95K produced a large false translucent rectangle at an exactly edge-on flight pose. The cause was a singular OpenCV homography in the QA renderer. Degenerate zero-area flight planes are now skipped there, matching the physical/WebGL zero-area case.
5. The WebGL renderer also culls only the mathematically degenerate edge-on transparent plane to avoid driver-dependent raster artefacts.

After these corrections the reviewed source-vs-render and pose panels no longer show the original broken/kinked shaft class or the QA rectangle artefact.

## Known limits

- A single product view still cannot provide source-grounded 360° flight artwork.
- Plane B is still approximated for designs without an independent source.
- `NEEDS_MANUAL_REVIEW` intentionally remains possible even when the rendered shaft-core is safe. It means the source does not support a confident automatic root decision, not that an arbitrary crop is accepted.
- Root render length is a source-proportion-derived visual heuristic within a conservative range, not a manufacturer dimension.
- V1.3.3 fixes the Tail/Shaft continuity pipeline; it does not solve every wider design-reconstruction limitation of the renderer.
