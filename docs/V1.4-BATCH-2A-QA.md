# V1.4 – Batch 2A Flight QA

Stand: 04.10.2026

## Scope

Batch 2A covers only:

- Gabriel Clemens G2
- Target Luke Littler G1 Prodigy
- Target Shift SP

No changes are made to `autodarts-xconfig`.

## Root cause addressed

V1.3.x could still derive the renderer `planeProfile` from a photographed side-view flight silhouette. That silhouette already contains photographic perspective and, for folded/integrated systems, evidence of the perpendicular fin.

For known flight families this is the wrong source for canonical 3D geometry.

V1.4 Batch 2A therefore separates:

1. source-grounded artwork pixels,
2. canonical flight-fin geometry.

The artwork remains source-derived. The alpha/mesh envelope is constrained to the known mounted flight shape.

## Red-team result

### Resolved in this batch

- photographed silhouette used as canonical fin geometry
- photographed cross-fin protrusion influencing final mesh silhouette
- accidental regression from known No.2/No.6 geometry back to image-derived profile
- loss of provenance distinction between artwork and geometry

### Explicitly not claimed

This batch does **not** prove that a complete product photograph and an orthogonal 3D render should be pixel-identical. They may show different roll, incidence and already-projected flight faces.

This batch also does not reconstruct unknown reverse-side artwork. Plane B remains APPROXIMATED.

## Batch 2A decision

**PASS for the intended V1.4 Batch 2A scope.**

The three presets are suitable to use as the reference implementation for applying the same artwork/geometry separation to the next source-grounded presets.
